# withJZ

**AI media and consumer products, run by agents.**

withJZ LLC is an LGBTQ+-owned, self-funded AI media and consumer technology
company. Founded 2023 in Wyoming, run 100% remotely from Europe. We build the
agent pipelines that publish and run our own brands.

## Products

| Product | What it is |
|---|---|
| [TrueQueer](https://truequeer.com) | Independent LGBTQ+ journalism. 77k+ monthly visits. Live since 2022; moved from manual publishing to AI-driven. |
| [Signal Sentry](https://signalsentry.ai) | AI signal, twice a day: an automated brief of the top AI news, with why each story matters. |
| MyGenealogy.AI | AI-assisted family history research. In development. |

## How we build

- **Agent publishing pipelines:** agents collect, check, write and publish on a schedule.
- **Sourced by default:** every Signal Sentry story links to where it came from.
- **Record matching:** AI-assisted matching of genealogy records.

Most of our code is private. Public tools will land here as we open-source them.
